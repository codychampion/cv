# Cody Champion — CV / Portfolio

Personal CV and portfolio site — enterprise AI / agentic systems, geospatial and applied ML, with experience, selected publications, projects, and awards.

Live at [codychampion.bitsandbeakers.com](https://codychampion.bitsandbeakers.com).

Zero-build static site: React 18 (UMD) + Babel-standalone, no bundler, no `package.json`. Open `index.html` directly in a browser — no dev server required. A self-contained printable version lives in `print.html` (browser Print / Save as PDF).
